# quips-c-uv-led
Design for UV LEDs intended for QUIPS-C experiment, includes CAD-models of mount and PCB

# Parts
- LED: Luminus Devices SST-08-UV-A40H-F365-00 
- Resistor: Vishay CRCW12184R02FKEKHP
- Connector: JST_PH_B2B-PH-K_1x02_P2.00mm_Vertical
